## Definition

Let $n$ be a positive integer. Two integers $a, b \in \mathbb{Z}$ are **congruent modulo $n$**, written:

$$a \equiv b \pmod{n}$$

if $n$ divides their difference $a - b$ ($n \mid (a - b)$).

- Modular arithmetic defines an equivalence relation on $\mathbb{Z}$, partitioning integers into $n$ residue classes $\mathbb{Z}_n = \{0, 1, 2, \dots, n-1\}$.

---

## Modular Operations

If $a \equiv c \pmod{n}$ and $b \equiv d \pmod{n}$, then:

| Operation | Property |
|---|---|
| **Addition** | $a + b \equiv c + d \pmod{n}$ |
| **Subtraction** | $a - b \equiv c - d \pmod{n}$ |
| **Multiplication** | $a \cdot b \equiv c \cdot d \pmod{n}$ |
| **Exponentiation** | $a^k \equiv c^k \pmod{n} \quad (k \ge 0)$ |

> [!warning] Modular Division Requires Coprimality
> You cannot simply divide both sides of a congruence by $c$.  
> $ac \equiv bc \pmod{n} \implies a \equiv b \pmod{\frac{n}{\gcd(c, n)}}$.  
> In particular, if $\gcd(c, n) = 1$, then $a \equiv b \pmod{n}$.

## Fundamental Theorems

### Fermat's Little Theorem

> [!example] Fermat's Little Theorem
> If $p$ is a prime number and $a$ is an integer such that $p \nmid a$, then:
> $$a^{p-1} \equiv 1 \pmod{p}$$
> Equivalent form for all $a \in \mathbb{Z}$: $a^p \equiv a \pmod{p}$.

### Euler's Totient Function & Theorem

Euler's totient function $\phi(n)$ counts the number of integers $k \in \{1, 2, \dots, n\}$ coprime to $n$.

> [!example] Euler's Generalization
> If $\gcd(a, n) = 1$, then:
> $$a^{\phi(n)} \equiv 1 \pmod{n}$$

### Chinese Remainder Theorem (CRT)

> [!example] Chinese Remainder Theorem
> Let $n_1, n_2, \dots, n_k$ be pairwise coprime positive integers. Then the system of linear congruences:
> $$x \equiv a_1 \pmod{n_1}, \quad x \equiv a_2 \pmod{n_2}, \quad \dots, \quad x \equiv a_k \pmod{n_k}$$
> has a **unique** solution modulo $N = n_1 n_2 \cdots n_k$.

## Practice Problems

1. Compute $7^{222} \bmod 11$ using Fermat's Little Theorem.
2. Find the last digit of $3^{100}$ by evaluating $3^{100} \pmod{10}$ with Euler's Theorem.
3. Solve the linear congruence $5x \equiv 3 \pmod{7}$.
4. Use the Chinese Remainder Theorem to find the smallest positive solution to:
   $$x \equiv 2 \pmod{3}, \quad x \equiv 3 \pmod{5}, \quad x \equiv 2 \pmod{7}$$
5. Calculate $\phi(360)$ using prime factorization.

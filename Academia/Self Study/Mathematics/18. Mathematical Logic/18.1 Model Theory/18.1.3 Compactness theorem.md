## Compactness Theorem

> [!example] Compactness Theorem of First-Order Logic
> A set of first-order sentences $T$ has a model if and only if **every finite subset** $T_0 \subseteq T$ has a model.

---

## Proof via Completeness Theorem

The Compactness Theorem is a direct algebraic corollary of the Completeness and Soundness Theorems:

1. If $T$ has no model, then $T \models \bot$.
2. By Completeness, $T \vdash \bot$.
3. Since a formal proof contains only finitely many steps, it can only use finitely many axioms from $T$. Thus there exists a finite $T_0 \subseteq T$ such that $T_0 \vdash \bot$.
4. By Soundness, $T_0 \models \bot$, so $T_0$ has no model.

## Non-Standard Models

The Compactness Theorem is the central tool for constructing **non-standard models** in mathematics.

> [!example] Non-Standard Models of Arithmetic
> Add a new constant symbol $c$ to the language of arithmetic $\mathcal{L}_{\text{PA}} = \{+, \cdot, 0, 1, <\}$ and consider:
> $$T = \text{PA} \cup \{c > 0, c > 1, c > 2, c > 3, \dots\}$$
> Every finite subset $T_0 \subset T$ is satisfied by the standard natural numbers $\mathbb{N}$ (choosing $c$ larger than all finite bounds in $T_0$).  
> By Compactness, $T$ has a model $\mathcal{N}^*$ containing an **infinite non-standard integer** $c$!

## Practice Problems

1. State the Compactness Theorem of first-order logic.
2. Use Compactness to prove that graph reachability ("there is a path of arbitrary finite length between $u$ and $v$") cannot be expressed by a single first-order sentence.
3. Show that first-order logic cannot express the concept of a finite set (i.e. there is no theory whose models are precisely all finite structures).
4. Construct a non-standard model of the real numbers $\mathbb{R}^*$ containing infinitesimal elements using Compactness.
5. Explain how the name "Compactness Theorem" relates to topological compactness in Stone space.

## Decidable vs Turing-Recognizable Languages

Let $L \subseteq \Sigma^*$ be a language.

| Class | Definition | Behavior on Inputs |
|---|---|---|
| **Turing-Recognizable** (Recursively Enumerable / RE) | A TM $M$ accepts $w \iff w \in L$. | If $w \in L$, $M$ accepts. If $w \notin L$, $M$ may reject or loop forever. |
| **Decidable** (Recursive / Decidable) | A TM $M$ halts on **all** inputs, accepting $w \in L$ and rejecting $w \notin L$. | $M$ always halts in finite time for any input string. |

## The Halting Problem

Define the Halting Problem language:

$$A_{\text{TM}} = \{\langle M, w \rangle \mid M \text{ is a TM and } M \text{ accepts } w\}$$

> [!example] Turing's Undecidability Theorem (1936)
> The language $A_{\text{TM}}$ is **undecidable**. No algorithm can determine whether an arbitrary Turing machine will halt and accept a given input.

### Proof by Diagonalization

Assume a decider $H$ exists for $A_{\text{TM}}$. Construct machine $D(\langle M \rangle)$:
1. Run $H$ on $\langle M, \langle M \rangle \rangle$.
2. If $H$ accepts, $D$ rejects; if $H$ rejects, $D$ accepts.

Running $D(\langle D \rangle)$ yields a contradiction: $D$ accepts $\langle D \rangle \iff D$ rejects $\langle D \rangle$. Thus no such decider $H$ can exist!

---

## Reducibility

To prove a language $L$ is undecidable:
1. Assume $L$ is decidable by machine $R$.
2. Use $R$ as a subroutine to construct a decider for $A_{\text{TM}}$.
3. Conclude $L$ is undecidable.

## Practice Problems

1. Define the difference between a decidable language and a Turing-recognizable language.
2. State the Halting Problem $A_{\text{TM}}$ and outline Turing's proof of its undecidability.
3. Show that if a language $L$ and its complement $\bar{L}$ are both Turing-recognizable, then $L$ is decidable.
4. State Rice's Theorem regarding non-trivial semantic properties of programs.
5. Use a reduction from $A_{\text{TM}}$ to prove that $HALT_{\text{TM}} = \{\langle M, w \rangle \mid M \text{ halts on } w\}$ is undecidable.

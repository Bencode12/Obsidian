## Definition

A **partially ordered set** (or **poset**) is a pair $(P, \le)$ where $P$ is a set and $\le$ is a binary relation on $P$ satisfying three axioms:

| Axiom | Condition | Description |
|---|---|---|
| **Reflexivity** | $\forall x \in P, \; x \le x$ | Every element is comparable to itself. |
| **Antisymmetry** | $\forall x, y \in P, \; (x \le y \text{ and } y \le x) \implies x = y$ | No distinct elements mutually precede each other. |
| **Transitivity** | $\forall x, y, z \in P, \; (x \le y \text{ and } y \le z) \implies x \le z$ | Order cascades transitively. |

---

## Chains and Antichains

Let $(P, \le)$ be a poset.

- A subset $C \subseteq P$ is a **chain** if any two elements in $C$ are comparable ($\forall x, y \in C \implies x \le y \text{ or } y \le x$).
- A subset $A \subseteq P$ is an **antichain** if no two distinct elements in $A$ are comparable ($\forall x \neq y \in A \implies x \nleq y \text{ and } y \nleq x$).

---

## Dilworth's Theorem

> [!example] Dilworth's Theorem (1950)
> In any finite poset $(P, \le)$, the minimum number of chains needed to cover $P$ is equal to the maximum size of an antichain in $P$.

## Practice Problems

1. Verify that the power set $\mathcal{P}(X)$ under subset inclusion $\subseteq$ is a poset.
2. Draw the Hasse diagram for the divisor poset of 12: $D_{12} = \{1, 2, 3, 4, 6, 12\}$ under divisibility.
3. State Dilworth's Theorem and find the maximum antichain in $D_{12}$.
4. State Sperner's Theorem regarding maximum antichains in the Boolean lattice $\mathcal{P}(\{1, \dots, n\})$.
5. Explain the dual of Dilworth's Theorem (Mirsky's Theorem).

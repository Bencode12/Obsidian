## Definition

A **matroid** is a finite combinatorial structure $M = (E, \mathcal{I})$ consisting of a finite ground set $E$ and a collection $\mathcal{I} \subseteq \mathcal{P}(E)$ of **independent sets** satisfying:

| Axiom | Condition |
|---|---|
| **Non-emptiness** | $\varnothing \in \mathcal{I}$ |
| **Hereditary Property** | If $I \in \mathcal{I}$ and $J \subseteq I$, then $J \in \mathcal{I}$. |
| **Independent Set Exchange** | If $A, B \in \mathcal{I}$ with $|A| > |B|$, there exists $x \in A \setminus B$ such that $B \cup \{x\} \in \mathcal{I}$. |

---

## Standard Examples of Matroids

> [!example] Vector (Linear) Matroid
> Let $E$ be a finite set of vectors in a vector space $V$. A subset $I \subseteq E$ is independent if the vectors in $I$ are linearly independent.

> [!example] Graphic Matroid $M(G)$
> Let $E$ be the set of edges of a finite graph $G$. A subset $I \subseteq E$ is independent if $I$ contains no cycles (i.e. $I$ forms a forest).

---

## Rank Function

The **rank function** $r : \mathcal{P}(E) \to \mathbb{N}$ assigns to each $X \subseteq E$ the size of a maximal independent subset contained in $X$:

$$r(X) = \max \{ |I| \mid I \in \mathcal{I}, I \subseteq X \}$$

## Practice Problems

1. Verify that graphic matroids satisfy the Independent Set Exchange Axiom.
2. Define what a **basis** and a **circuit** of a matroid are.
3. Show that all bases of a matroid $M = (E, \mathcal{I})$ have the exact same size $r(E)$.
4. Explain how Greedy Algorithms (e.g. Kruskal's algorithm for minimum spanning trees) find optimal bases in weighted matroids.
5. State the Rank Function Axioms for a matroid.
